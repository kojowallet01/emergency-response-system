## 3 Simple Steps

### 1️⃣ Create App Icons (2 minutes)
Open on your computer: `http://localhost:3000/create-icons.html`
- Click "Download icon-192.png"
- Click "Download icon-512.png"  
- Move both files to `/frontend/public/` folder
- Restart server: Stop (Ctrl+C) and run `npm run dev` again

### 2️⃣ Access on Mobile
Make sure your phone is on the **same WiFi** as your computer, then:
- Open browser on your phone
- Go to: `http://172.20.10.6:3000`
- Test the emergency reporting page

### 3️⃣ Install as App (Optional)
**iPhone**: Safari → Share → Add to Home Screen  
**Android**: Chrome → Menu → Add to Home Screen
