# App Icons Setup

## Missing Files
You need to create these two icon files:
- `icon-192.png` (192x192 pixels)
- `icon-512.png` (512x512 pixels)

## Quick Method
1. Open: `http://localhost:3000/create-icons.html`
2. Download both icons
3. Place them in this folder (`/frontend/public/`)
4. Restart the server

## Alternative: Use Online Tool
Visit: https://favicon.io/favicon-generator/
- Create icons with emergency symbol (🚨 or !)
- Download and rename files
- Place in this folder

## Why These Icons?
These icons are used for:
- PWA home screen icon
- Browser tab favicon
- App splash screen
- Bookmark icon

## After Adding Icons
1. Restart Next.js server
2. Clear browser cache
3. Reinstall PWA if already installed
4. Icons should now appear!
